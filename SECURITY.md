# Security Policy

## Supported versions

Fixes go into the latest v1.x minor release. A fix ships as a new patch or
minor version; published tags are never moved.

## Reporting a vulnerability

Report it privately through
[GitHub's advisory form](https://github.com/Sriram-PR/go-ignore/security/advisories/new),
not in a public issue. Include the go-ignore and Go versions, the patterns and
paths involved, and what goes wrong (for example a crash, unbounded CPU or
memory, or a file read outside the work tree).

This is a one-person project, so responses are best effort. You'll get a reply
in the advisory thread, and credit in the release notes if you want it.
